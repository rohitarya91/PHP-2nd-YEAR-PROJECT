USER DASHBOARD BACKEND EXPLANATION
File: dashboard/user_dashboard.php
Helper File Used: config/store.php

IMPORTANT NOTE
- Aapke tabs me includes/store.php dikh raha hai, lekin current user_dashboard.php actually config/store.php use kar raha hai.
- Isliye real backend explanation ka major logic config/store.php se aa raha hai.

==================================================
1. YE FILE OVERALL KYA KARTI HAI
==================================================
Ye file user dashboard ka backend + display logic handle karti hai.

Simple language me:
- User login hai ya nahi check karti hai
- Admin ko user dashboard me aane se rokti hai
- Add to Cart form handle karti hai
- Products database se laati hai
- User ke orders laati hai
- Cart ka total count nikalti hai
- Fir ye sab data HTML me dikha deti hai

Real life example:
Socho aap Blinkit ya grocery app bana rahe ho.
User dashboard khulta hai:
- Upar user ka naam dikh raha hai
- Products dikh rahe hain
- Cart count dikh raha hai
- Orders history dikh rahi hai
Ye sab backend isi file aur helper ke through aata hai.

6. SQL QUERIES JO BACKEND ME USE HO RAHI HAIN
==================================================

Query 1:
SELECT id, name, price, description, image, created_at
FROM products
WHERE name LIKE ? OR description LIKE ?
ORDER BY id DESC

Breakdown:
- SELECT = kaunsa data chahiye
- FROM products = products table se data chahiye
- WHERE = filter lagana hai
- LIKE = matching text search karna hai
- OR = name ya description dono me dekhna hai
- ORDER BY id DESC = newest products pehle

Example:
Agar search "milk" hai to naam ya description me milk wale products aayenge.


Query 2:
SELECT id, name, price, description, image, created_at
FROM products
ORDER BY id DESC

Meaning:
- Sare products lao
- Latest product sabse pehle dikhao


Query 3:
SELECT id, total_amount, status, created_at
FROM orders
WHERE user_id = ?
ORDER BY id DESC

Meaning:
- Sirf current login user ke orders lao
- Sabhi users ke nahi

Why:
- User apna hi order history dekhe


Query 4:
SELECT id, name, price, description, image
FROM products
WHERE id IN (?, ?, ?)

Meaning:
- Session cart me jitne product ids hain
- Un sabka data ek hi query me lao

Why:
- Cart page aur totals nikalne ke liye product info chahiye

7. IMPORTANT PHP FUNCTIONS EXPLAINED
==================================================

1. session_start()
Kya karta hai:
- Session start karta hai

Kyu use hota hai:
- Login data aur cart data store rakhne ke liye

Example:
- User login hua
- Session me user id save hui


2. require_once()
Kya karta hai:
- File ko ek hi baar include karta hai

Kyu use hota hai:
- Duplicate include se bachne ke liye


3. header("Location: ...")
Kya karta hai:
- Redirect karta hai

Kyu:
- Login page bhejne ke liye
- Form submit ke baad wapas section pe lane ke liye


4. exit()
Kya karta hai:
- Script execution turant rok deta hai

Kyu:
- Redirect ke baad neeche ka code chalna nahi chahiye


5. trim()
Kya karta hai:
- String ke start/end ke extra spaces hata deta hai

Example:
" apple " ko "apple" bana dega


6. htmlspecialchars()
Kya karta hai:
- HTML special characters ko safe banata hai

Kyu:
- XSS type attack se bachne ke liye

Example:
Agar koi user name me <script> likh de to wo run na ho


7. $conn->prepare()
Kya karta hai:
- SQL query ko prepared form me banata hai

Kyu:
- SQL injection risk kam hota hai


8. bind_param()
Kya karta hai:
- Query ke placeholders me actual values dalta hai

Example:
WHERE user_id = ?
Yaha ? ki jagah real id jayegi


9. execute()
Kya karta hai:
- Prepared query run karta hai


10. fetch_assoc()
Kya karta hai:
- Ek row ko associative array me deta hai

Example output:
[
  'name' => 'Apple',
  'price' => 200
]


11. mysqli_query()
Note:
- Is file me direct mysqli_query() use nahi hua
- But concept same hai jo $conn->query() karta hai

Kya karta hai:
- SQL query directly run karta hai


12. move_uploaded_file()
Note:
- Ye user_dashboard.php me direct use nahi hua
- Lekin same backend project ke helper me admin image upload ke liye use hota hai

Kya karta hai:
- Uploaded file ko temporary location se actual uploads folder me move karta hai

Why:
- Product image permanently save karne ke liye

13. MISTAKES / IMPROVEMENTS
==================================================

1. fetch_all_products() do baar call ho raha hai
Current:
$products = fetch_all_products($conn, $search);
$homeProducts = array_slice(fetch_all_products($conn), 0, 10);

Problem:
- Database ko 2 baar hit kar raha hai

Simple fix:
$allProducts = fetch_all_products($conn, $search);
$products = $allProducts;
$homeProducts = array_slice($allProducts, 0, 10);


2. Home products search ignore kar rahe hain
Current:
Home products hamesha full products se aa rahe hain

Simple fix:
Agar aap chaho to homeProducts bhi search ke according bana sakte ho


3. Section switching mostly JS based hai
Problem:
- Browser refresh pe exact same state har baar preserve nahi hoti

Simple fix:
- URL me active section hamesha update karo


4. Admin check email se ho raha hai
Current:
admin@gmail.com fixed check

Problem:
- Scale karne par weak ho jata hai

Simple fix:
- users table me role column add karo


5. ensure_store_schema() har request pe chal raha hai
Problem:
- Har page load pe schema check ho raha hai

Simple fix:
- Future me isko install/setup script me shift kar sakte ho
